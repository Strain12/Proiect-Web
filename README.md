Proiect: Site Web cu React

Descriere: Site personal care prezinta o lista cu proiectele creeate de mine.

Tehnologii folosite: 1. Node.js si Express pentru framework-ul principal de api 
                     2. MongoDB pentru baza de date NoSQL si Mongoose pentru schemele datelor
                     3. React pentru frontend

BootUp: Trebuie instalate in terminalul principal urmatoarele tehnologii:
            1. npm install
            2. npm insall react-dom
            3. npm install react-router
        Trebuie instalate in terminalul din folderul "server: urmatoarele:
            1. npm install cors
            2. npm install uuid 
        In terminalul folderului principal (cel care contine folderul src) trebuie rulata comanda 
            npm run dev
        In terminalul folderului "server" trebuie rulata comanda 
            node index.js
